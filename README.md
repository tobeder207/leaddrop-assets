# leaddrop-assets

Öffentlich ausgelieferte Mediendateien für leaddrop.de.

Ausgeliefert über jsDelivr:

    https://cdn.jsdelivr.net/gh/<user>/leaddrop-assets@main/<datei>

Nicht `raw.githubusercontent.com` verwenden — GitHub drosselt das und
liefert Videos teils mit falschem Content-Type aus.

## Dateien

| Datei | Verwendung | Format |
|---|---|---|
| `leaddrop-hero.mp4` | Hintergrundvideo im Header | 960×540, 24 s, 13 MB |

Beim Austausch einer Datei einen neuen Dateinamen vergeben
(`…-v2.mp4`), weil jsDelivr aggressiv cached.
